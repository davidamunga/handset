Let a script or an AI agent drive the phone. Start Handset with `--ctl` (or set `ctl=on`) and use `handset ctl screenshot`, `tap`, `swipe`, `type`, `key` and more to see and control the phone without touching the window. It is off by default, protected by a secret only you can read, and the window shows when a program is using it. See `docs/agents.md`.
