`handset mcp` gives AI agents the phone as tools. It is an MCP server for Claude Code, Claude Desktop, Cursor, VS Code and other MCP clients: `claude mcp add handset -- handset mcp`, with Handset running with `--ctl`. The agent can read the screen as text or as an image, tap by what an element says, swipe, type, press keys, open apps and wait for something to appear. See `docs/agents.md`.
