Linux now has the right-click menu. Handset draws it in its window, in the same dark style as the toolbar, because there is no native menu to use there: right-click the phone or click the toolbar's "…" button to reach frames, recording settings, recent captures, apps, the connection and updates (including Skip and Remind Me). Submenus open beside their item, long lists such as the apps scroll, the arrow keys, Enter and Escape work, and the menu never shows in screenshots or recordings. On macOS and Windows the native menu is unchanged; set `HANDSET_DRAWN_MENU=1` to try the drawn one there.
