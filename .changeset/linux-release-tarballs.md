Each release now includes a Linux download for x86_64 and aarch64 (`Handset-<version>-linux-<arch>.tar.gz`, experimental, for glibc 2.35 or newer such as Ubuntu 22.04 and Debian 12), listed in a signed `SHA256SUMS-linux` that `handset --verify-release` checks. The website's Linux card links to the file for your computer.
